# CopyPop 交付验证

验证日期：2026-11-01。当前 Mac 为 Apple Silicon。

通过：
- Swift XCTest 2 项，0 失败：跨内容累计、跨重启只保留总数、只保存日期/总数、午夜重置、敏感内容不做重复识别。
- arm64 与 x86_64 均编译成功，lipo 确认通用二进制；本地签名完整性验证通过。
- LaunchServices 成功启动应用，原生 AppKit/SwiftUI 窗口实际运行。
- 隔离测试剪贴板 A→B→A：总数 3，最后显示 Copy × 2。
- 未确认的复制与空剪贴板均不增加计数；HUD 预览不增加计数。
- 深浅色原生视图分别渲染并人工检查：两行完整、无裁切，窗口高 72px。
- 更新后仅 1 个 HUD 窗口；淡出后 alpha 为 0。

证据见 ui-verification.json、HUD-light.png、HUD-dark.png。PNG 是应用自身视图的渲染结果，毛玻璃在实际桌面上会随背后内容变化。

未实测：用户授予输入监控后的真实跨应用 ⌘C 事件、Intel 机器实际运行、多显示器/全屏切换。未确认复制的处理分支已通过隔离测试，但不等同于权限链路验证。

发行限制：本地临时签名，未做 Apple 公证。不包含开发者证书；其他 Mac 可能需要用户在系统设置中允许打开。
